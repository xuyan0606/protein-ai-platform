# 4G木聚糖酶突变体数据库使用说明（合并分析版）

## 一、数据概览

|项目|内容|
|-|-|
|酶名称|4G木聚糖酶|
|载体|PICZa-4G（毕赤酵母表达载体）|
|宿主菌|毕赤酵母（Pichia pastoris）|
|表达方式|分泌表达（酶分泌至培养上清，无细胞破碎步骤）|
|样品来源|培养上清液直接稀释后测酶活|
|测定方法|DNS法|
|反应条件|37度, 30min, 稀释10000倍(Round 1) / 试管复测(Round 2A/2B)|
|酶活计算公式|酶活 = ((((OD x 0.8627)+0.0804)/(180.2 x 30)) x 1000) x 10000 (U/mL)|
|标准曲线|C(ug/mL) = 0.8627 x OD + 0.0804（木糖为标准品, 分子量180.2）|
|实验轮次|Round 1(96孔板, 去异常值) + Round 2A(小筛试管复测, 图表1) + Round 2B(I153V克隆对比验证, 图表2)|
|批次数量|Round 1: 3批次(B1-B3); Round 2A: 1批次(B4); Round 2B: 1批次(B5)|
|突变体数|11个突变体 + 1个野生型对照(PICZa-4G)|
|Round 1测量记录|288条孔级数据|
|Round 2A测量记录|19条试管复测数据(含酶活, 蛋白浓度, 比活)|
|Round 2B测量记录|8条克隆对比验证数据(酶活)|
|数据生成日期|2026-07-14|
|数据来源|合并"去异常值分析"与"试管复测分析"两个版本|

## 三、异常值清洗规则（Round 1）

1. 每个样本去掉1个最小OD值
2. 每个样本去掉1个最大OD值
3. 剩余值用IQR法(1.5xIQR)剔除异常值
4. 保留值用于计算均值酶活

## 九、注意事项

* **表达体系说明：本数据为毕赤酵母分泌表达体系，酶分泌至培养上清，测定酶活时直接取上清稀释后检测，全程无细胞破碎步骤。低酶活记录的混杂因素为表达水平/上样量/样品制备差异，不涉及破碎效果。**
* Round 2A/2B数据来源于图表截图的估计值, 非原始仪器数据
* I153V结论已修正为"无显著效应", 请勿再使用图表1高酶活值作为正向证据
* 对于AI分析, 建议优先使用A级数据(多轮覆盖), B级数据作为辅助参考
