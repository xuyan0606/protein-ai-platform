# Protein AI Platform — 安全审查报告

**审查范围：** backend/app/api/, app/core/, black-box API 全量
**99 测试通过，覆盖率 29%**

---

## 🔴 Critical

### 1. POST /api/projects — 空 name 被接受
`app/api/projects.py:20` — `ProjectCreate.name: str` 无 `min_length`
- **复现：** `POST /api/projects {"name":""}` → 201 Created
- **修复：** 加 `Field(min_length=1)`

### 2. POST /api/auth/register — name 过长导致 500
`app/api/auth.py:36` — `RegisterRequest.name` 无 `max_length`，DB String(200)
- **复现：** 5000字符 name → 500 Internal Server Error
- **修复：** `name: str = Field(max_length=200)`

### 3. POST /api/auth/register — email 未验证格式
`app/api/auth.py:34` — `email: str` 应为 `EmailStr`
- **复现：** `"email":"notanemail"` → 被 Pydantic 接受
- **修复：** 改为 `email: EmailStr`

### 4. XSS — 项目名存 `<script>` 标签未清洗
`app/api/projects.py` — 存储原始 HTML 到 DB，前端渲染时可能 XSS
- **复现：** `"name":"<script>alert(1)</script>"` → 201 成功存储
- **修复：** 输出时 `Content-Type: text/plain` 或前端 `textContent` 渲染

### 5. 未认证端点泄露工具列表
`app/api/tools.py:9-14` — GET /api/tools 无需认证即可列出全部工具
- **影响：** 攻击者可枚举攻击面
- **修复：** 加 `Depends(get_current_user)` 或最小化公开信息

---

## 🟠 High

### 6. 登录/注册无限速
`app/api/auth.py:74,107` — 无 `RATE_LIMIT_REQUESTS` 生效的中间件
- **影响：** 暴力破解可行
- **修复：** 加 rate limiter 中间件到 auth 路由

### 7. Refresh token 异常静默处理
`app/api/auth.py:141` — `except Exception:` 捕获所有异常（包括 JWT 过期以外的异常）
- **影响：** 真实的系统错误被伪装成 "Invalid or expired refresh token"
- **修复：** 只捕获 `JWTError`

### 8. 文件上传缺扩展名校验
`app/api/files.py:43` — 任何扩展名都接受
- **影响：** 可能上传 .py/.sh/.exe 等可执行文件
- **修复：** 限制白名单扩展名（.pdb, .fasta, .cif, .json, .txt）

---

## 🟡 Medium

### 9. Cookie secure flag 本地关闭
`app/api/auth.py:94` — `secure=False`，生产环境必须 `True`
- **修复：** 用 settings 控制

### 10. SSE 连接泄漏风险
`app/api/chat.py:96-97` — 100% 覆盖率缺口，测试未覆盖 sse-event-loop 的错误路径

### 11. 默认后端 SECRET_KEY 弱
`app/core/config.py:12` — `SECRET_KEY: str = "dev-secret-change-in-production"`，.env 覆盖但默认不安全

### 12. 部分 API 未保护（/api/chat/models）
`app/api/chat.py:191-194` — 公开可访问，泄露模型列表
