# AI酶改造平台人工分析流程 v1 固化说明

## 定位

从 2026-07-29 起，平台内酶改造分析默认按“先认识这条酶，再结合目标选择分析路径，最后整合证据形成候选建议”的流程执行。

这份文档用于把人工分析主流程固化为平台流程设计和 agent 执行协议，不作为具体工具的强制穷举清单。

## 默认主流程

0. 策略确认
   - 平台先输出分析策略、工具调用流程和关键参数。
   - 用户确认后才执行工具。
   - 用户提出修改策略时，平台重新生成策略，不直接执行。

1. 输入整理
   - 提取并标准化用户提供的项目描述、蛋白序列、结构文件/PDB 编号、改造目标、物种、表达体系、底物和实验现象。
   - 输出标准化序列、结构状态、目标描述和补充条件。

2. 基础核验
   - 检查序列合法性、长度、疑似截断、信号肽/跨膜区风险和目标描述清晰度。
   - 输出序列基本状态、初步结构风险和是否具备后续分析基础。

3. 结构获取
   - 优先使用用户上传的实验结构或 PDB/mmCIF。
   - 其次检索 PDB/PDBe、AlphaFold DB。
   - 没有可用结构且用户允许时，再调用 AlphaFold/ESMFold/RoseTTAFold 类预测。
   - 输出结构来源和可用结构状态。

4. 最小基础画像
   - 建立酶的基本认识：物种来源、家族/超家族、候选 EC、关键 motif/催化中心、同源证据、结构和保守性认识。
   - 这是所有改造目标的共同前置步骤。

5. 目标识别与任务拆解
   - 识别主目标和次目标：热稳定性、活性/比活力/催化效率、底物特异性、表达/溶解性、pH/溶剂/金属离子耐受性。
   - 将目标拆成后续专项分析问题。

6. 目标相关深分析
   - 热稳定性：保守性、柔性区/环区、结构核心、盐桥、氢键、二硫键、稳定性案例。
   - 活性/比活力：催化中心、活性口袋、关键残基几何关系、同源功能证据、反应信息。
   - 底物特异性：口袋大小与形状、通道/入口、底物谱、同源酶偏好、目标底物结构特征。
   - 表达/溶解性：表面疏水性、聚集倾向、信号肽、跨膜区、表面电荷分布。
   - pH/溶剂/离子耐受：表面电荷、金属结合、同源案例和结构/文献证据。

7. 证据检索与工具执行
   - 不同目标进入不同工具组合，不走同一套固定流程。
   - 记录实际使用的数据源、工具、证据结果和失败/blocked 原因。

8. 候选策略生成
   - 结合序列、结构、基础画像、目标分析和证据结果，输出候选区域、候选位点、理由、优先级和预期影响方向。

9. 结果输出
   - 建议结构：用户目标理解、最小基础画像摘要、专项分析摘要、实际工具/数据源、候选区域/位点、候选理由、后续验证方向。

## 平台实现映射

当前后端 agent 协议已接入该流程：

- `backend/app/core/agent_roles.py`
  - `ENZYME_ENGINEERING_REPORT_PROTOCOL` 已改为人工分析流程 v1。
  - 约束 agent 不得直接从用户目标跳到突变建议。

- `backend/app/core/agent_graph.py`
  - fallback plan 对序列型酶改造任务默认先执行基础理化核验、结构状态获取、最小酶画像。
  - 后续再按热稳定性、活性/比活力、底物特异性、表达/溶解性等目标路由工具。
  - 上传结构优先于 ESMFold，不重复预测已上传结构。
  - 默认先返回策略确认，不执行工具；只有收到 `execute_confirmed` 控制请求后才进入工具执行。

- `frontend/src/components/chat/ChatInput.tsx`
  - 等待策略确认时显示“确认执行”和“修改策略”入口。
  - 修改策略只重新生成计划；确认执行才调用工具。

- `backend/tests/test_agent_binder.py`
  - 已增加回归断言：同一序列不同目标的工具链不同，但共同前置为基础核验、结构获取和最小基础画像。
  - 已增加回归断言：默认 plan-only 不执行工具，确认后才执行。

## 优先跑通子流程

1. 热稳定性流程
   - 输入整理
   - 基础核验
   - 结构获取
   - 最小基础画像
   - 热稳定性深分析
   - 稳定性相关工具执行
   - 候选区域/位点生成
   - 结果输出

2. 底物特异性流程
   - 输入整理
   - 基础核验
   - 结构获取
   - 最小基础画像
   - 目标底物相关深分析
   - 口袋/通道/底物证据执行
   - 候选区域/位点生成
   - 结果输出

## 当前边界

- 该流程是分析顺序协议，不意味着每次都必须调用所有外部数据库或慢工具。
- 缺少结构、底物、编号映射或工具运行环境时，应输出结构状态或 blocked 原因，不伪造结果。
- 热稳定性和底物特异性为第一批优先产品化子流程。
