## 已复现的根因与改动

1. 前端在会话GET返回后才更新currentId，旧请求未检查选择代次；刷新恢复和退出后迟到列表也能覆盖状态。改为立即绑定选择，历史及策略检查点加载期间锁定发送、保留草稿，丢弃失效请求。加载失败保留错误，不创建本地假会话；上传期间换会话保留草稿/附件。请求体使用解析后的当前会话ID。
2. 上传优化请求被优先路由为research，确定性策略仍并行调用不被规划器使用的模型背景。明确优化路由为analyze，分析与设计规划不再调用该背景模型。保留真正research；不重试绕过模型拒答，不保证普通上游问答完全无误拒。
3. 明确发送“确认身份：名称”或“更正身份：名称”时，把名称绑定当前账号与实际序列哈希，写入已有身份记录表，不迁移数据库。新会话同序列复用名称，省去默认序列身份/BLAST检索；显式重识别/BLAST请求保留。局部身份/位点核查和结构保护继续。用户确认名称不是curated功能位点证据，未借此宣称定量实验收益。没有结构/序列、多链歧义或序列不一致时不保存。
4. ESM新增可选独立650M服务适配，严格核对输入、WT、完整有限分值、权重哈希、实际推理策略及原始证据。环境准备首次失败（pip旧版本及CPU索引缺构建依赖），保留失败回执；尚未据此称可用。默认无服务配置仍走原路径。
5. ColabFold支持运维显式启用service_local_search，按当前序列调用本地HHblits数据库，保留MSA来源/深度/哈希；保留提供本地MSA路径，禁止暗中公共检索。CPU部署仍限制2–400残基；未实算前不称接通。
