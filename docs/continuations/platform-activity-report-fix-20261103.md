## 修复行为

匿名、无可解析模板及已验证参考的理论模型收到比活力改造请求时，先进入身份与测定条件收集阶段。快速、标准、深度均使用同一输入链；联网允许时把BLAST安排在身份画像前；仅本地及禁用BLAST时遵守限制。原先已签名确认的计划不改写，后续候选设计仍需另行确认。

首轮暂停缺前置证据的目标候选门控、家族特异解释、候选排序、扫描和启发式kcat；保留输入解析、编号、理化性质、结构特征及身份画像。异步提交不会立即提供身份证据。当前补丁不实现检索完成后自动确认身份、自动续跑设计或覆盖旧报告。

单链理论模型身份未明且同源任务待完成时，输出简洁阶段进展，列明已有序列、查询状态及真正待补的底物/浓度、测定条件、WT U/mg与蛋白纯度。原工具卡保留。该进展在交付状态上为`NEEDS_REVIEW`，不能因生成了Markdown变成`READY`。
