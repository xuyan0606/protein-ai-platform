# 初步耐热位点的替换类型偏向修复（2026-11-09）

## 原因与行为变化

原生成器把埋藏疏水残基各固定映射为一种替换（A→V、V→I、I→V、L→I、M→L），用序列位置抽取最多 60 个探针。SASA、接触数和 WT 原子完整性不等于检测到空腔，也没有检查新增侧链几何。评分后只按 Pareto、DDGun、风险及位置取唯一位置前 N 个，因此同类高分替换能够占据大部分名额。

修复如下：

- 候选池包含有明确来源的疏水侧链重排/尺寸探针：A→V、V→A、I→V/L、L→I/V、M→L。V→I 未做相应突变几何筛查，本轮不自动提出；不为凑数引入其他机制或无来源位点。
- 截取最多 60 个待评分探针前，按替换类型轮流分配并覆盖序列范围，避免单一残基组成或只取序列前段造成偏向。同类替换上限为请求数量的三分之一向上取整。
- 自动探针评分后仍应用同类替换上限，并保持每个位点最多一个替换。请求 12 个时，一种原残基→目标残基组合最多 4 个。该上限是可审阅的采样策略，不是验证过的生物效能阈值。仅显式提供候选、不含自动探针的请求不套用这个覆盖上限。
- DDGun 已预测不利的自动探针保留在完整筛查回执中，不因多样性补位而被选入；证据不足保留数量缺口。独立评分原值和 Pareto 层不为覆盖需求改写，也不生成综合成功率。
- A→V 使用实际 CA/CB/N 坐标建立局部框架，对三个理想化缬氨酸侧链构象检查非水重原子环境，包括其他链。新增甲基与邻居范德华半径之和重叠超过 0.6 Å 的构象不通过；三个构象都不通过时排除该自动探针。排除自身 CA/CB 的键合近邻比较。
- 上述几何方法只是固定环境中的严重重叠排查，未做侧链能量优化，不能证明所有构象均不可行或通过者无碰撞。其他类型明确标 `not_evaluated`。没有空腔检测、ΔTm、实验增益或成功概率结论。
- 报告列出生成与选中分布、几何排除记录、独立评分及覆盖约束。新增结构计算记录不把探索结果升级为正式实验集合。
