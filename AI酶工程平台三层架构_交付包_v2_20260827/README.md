## 0. 一句话定位

把"随便聊 → 按性质确定性路由 → 确定性调用工具 → 禁止把预测当实验结论"用三层约束锁死：
- **01 策略层**：只定义"该往哪个方向改"（22 张策略卡）。不决定工具调用。
- **02 路由层**：消费用户目标 → 选唯一 workflow_id → 建"人话标签 ↔ 真实 tool_id"交叉表 → 产出 IT 交接与待接入说明。
- **03 执行控制层**：真正能跑的 `enzyme-property-workflow-router` skill（SKILL.md + 14 个 references，含 58 工具目录）。
