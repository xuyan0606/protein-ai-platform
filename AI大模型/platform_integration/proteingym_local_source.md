# ProteinGym Local Source

P69 records the local ProteinGym source/reference package downloaded from the
official GitHub repository.

## Local Cache

- Source root: `cache/external/ProteinGym`
- File index: `datasets/benchmark/proteingym_local_source_files.jsonl`
- Manifest: `reports/proteingym_local_source_manifest.json`
- Report: `reports/proteingym_local_source_report.json`

## Use

This cache is useful for benchmark integration design, reference metadata,
scoring script inspection and future scorecard construction.

## Not Use

It is not a KWB model scorecard by itself. It is not a wet-lab label source, not
a training approval and not a model-quality claim.
