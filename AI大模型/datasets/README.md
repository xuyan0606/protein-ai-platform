# 数据集目录

本目录用于本地设计和存放 KWB 自研模型的数据集说明、样本 schema 和脱敏样例。

## 数据类型

- `raw/`：原始脱敏样本，仅本地研发使用。
- `curated/`：人工清洗后的训练样本。
- `features/`：序列、结构、注释、工具结果提取后的特征。
- `feedback/`：湿实验反馈、Go/Watch/No-Go、失败原因。

## 必备字段

- 酶名称、EC 编号、序列、结构来源。
- 底物、反应、pH、温度、表达体系。
- 突变位点、突变类型、实验结果。
- 证据来源、数据版本、人工审核状态。

## 原则

- 成功样本和失败样本都要保留。
- 每条训练样本必须能追溯到来源。
- 未脱敏数据不要进入可共享目录。
